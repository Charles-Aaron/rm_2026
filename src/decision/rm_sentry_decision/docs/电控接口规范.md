# 哨兵机器人导航 - 电控系统接口规范

## 1. 概述

本文档定义了哨兵机器人**导航系统**与**电控系统**之间的通信接口规范，用于姿态切换功能的指令传递和结果反馈。

> 注意：当前已切换为分离话题与分离消息（`/sentry/pose_command` + `/sentry/pose_result`）。
> 以第 2/3/7 节及源码实现为准；第 5 节部分历史示例仍在清理中。

**设计原则**：
- ✅ 使用描述性的消息名称，避免数字编号枚举
- ✅ 消息语义清晰，便于理解和维护
- ✅ 接口简洁，易于扩展

---

## 2. 通信架构

```
┌─────────────┐                    ┌─────────────┐
│  导航系统   │                    │  电控系统   │
│  (决策层)   │                    │  (执行层)   │
└──────┬──────┘                    └──────┬──────┘
       │                                  │
       │ /sentry/pose_command (导航→电控) │
       │────────────────────────────────>│
       │                                  │
       │ /sentry/pose_result (电控→导航)  │
       │<────────────────────────────────│
       │                                  │
       │  Command: SentryPoseCommand      │
       │  Result:  SentryPoseResult       │
       │                                  │
```

## 3. 消息定义

### 3.1 姿态命令消息（导航 -> 电控）

**Topic**: `/sentry/pose_command`

**Message Type**: `rm_decision_interfaces/msg/SentryPoseCommand`

```msg
uint8 pose_type  # 0=MOVEMENT, 1=ATTACK, 2=DEFENSE
```

### 3.2 姿态结果消息（电控 -> 导航）

**Topic**: `/sentry/pose_result`

**Message Type**: `rm_decision_interfaces/msg/SentryPoseResult`

```msg
uint8 pose_type    # 0=MOVEMENT, 1=ATTACK, 2=DEFENSE
bool pose_success  # true=执行成功, false=执行失败
```

**发布频率**: 事件驱动

**QoS 策略**: 
- Reliability: `RELIABLE`
- Durability: `VOLATILE`
- Depth: `10`

## 4. 通信流程

### 4.1 正常流程

```
导航系统                          电控系统
   │                                │
   │  /sentry/pose_command          │
   │  pose_type = 1 (ATTACK)        │
   │───────────────────────────────>│
   │                                │ 执行姿态切换
   │                                │
   │  /sentry/pose_result           │
   │  pose_type = 1                 │
   │  pose_success = true           │
   │  (成功)                        │
   │<───────────────────────────────│
   │                                │
   │  收到成功反馈，更新内部状态     │
```

### 4.2 异常流程

```
导航系统                          电控系统
   │                                │
   │  /sentry/pose_command          │
   │  pose_type = 1 (ATTACK)        │
   │───────────────────────────────>│
   │                                │ 执行失败
   │                                │ (如机械故障)
   │  /sentry/pose_result           │
   │  pose_type = 1                 │
   │  pose_success = false          │
   │<───────────────────────────────│
   │                                │
   │  收到失败反馈，记录日志         │
```

## 5. 电控系统实现示例

### 5.1 C++ 伪代码示例

```cpp
#include "rclcpp/rclcpp.hpp"
#include "rm_decision_interfaces/msg/sentry_pose.hpp"

class SentryController : public rclcpp::Node
{
public:
    SentryController()
    : Node("sentry_controller")
    {
        // 订阅导航指令（同一 Topic）
        pose_sub_ = this->create_subscription<rm_decision_interfaces::msg::SentryPose>(
            "/sentry/pose", 10,
            std::bind(&SentryController::pose_callback, this, std::placeholders::_1));
        
        // 发布执行结果（同一 Topic）
        pose_pub_ = this->create_publisher<rm_decision_interfaces::msg::SentryPose>(
            "/sentry/pose", 10);
    }

private:
    void pose_callback(const rm_decision_interfaces::msg::SentryPose::SharedPtr msg)
    {
        // 只处理 COMMAND 方向的消息
        if (msg->direction != "COMMAND") {
            return;
        }
        
        std::string pose_type = msg->pose_type;
        bool success = false;
        std::string message = "";
        uint32_t error_code = 0;
        
        RCLCPP_INFO(this->get_logger(), "Received pose command: %s", pose_type.c_str());
        
        // 执行姿态切换
        if (pose_type == "ATTACK") {
            std::tie(success, message, error_code) = switch_to_attack_pose();
        } else if (pose_type == "DEFENSE") {
            std::tie(success, message, error_code) = switch_to_defense_pose();
        } else if (pose_type == "MOVEMENT") {
            std::tie(success, message, error_code) = switch_to_movement_pose();
        } else {
            RCLCPP_WARN(this->get_logger(), "Unknown pose type: %s", pose_type.c_str());
            success = false;
            message = "Unknown pose type";
            error_code = 1;
        }
        
        // 反馈结果（RESULT 方向）
        auto result_msg = rm_decision_interfaces::msg::SentryPose();
        result_msg.direction = "RESULT";
        result_msg.pose_type = pose_type;  // 保持原姿态类型
        result_msg.success = success;
        result_msg.message = message;
        result_msg.error_code = error_code;
        result_msg.timestamp = now().nanoseconds();
        result_msg.is_valid = true;
        
        pose_pub_->publish(result_msg);
        
        RCLCPP_INFO(this->get_logger(), "Command %s executed, success: %d, message: %s", 
                   pose_type.c_str(), success, message.c_str());
    }
    
    std::tuple<bool, std::string, uint32_t> switch_to_attack_pose()
    {
        // TODO: 实现进攻姿态切换逻辑
        return {true, "Attack pose switched", 0};
    }
    
    std::tuple<bool, std::string, uint32_t> switch_to_defense_pose()
    {
        // TODO: 实现防御姿态切换逻辑
        return {true, "Defense pose switched", 0};
    }
    
    std::tuple<bool, std::string, uint32_t> switch_to_movement_pose()
    {
        // TODO: 实现移动姿态切换逻辑
        return {true, "Movement pose switched", 0};
    }
    
    rclcpp::Subscription<rm_decision_interfaces::msg::SentryPose>::SharedPtr pose_sub_;
    rclcpp::Publisher<rm_decision_interfaces::msg::SentryPose>::SharedPtr pose_pub_;
};
```

## 6. 导航系统实现说明

### 6.1 姿态指令发布

导航系统在 `PoseManager::switchPose()` 中发布指令：

```cpp
void PoseManager::publishPoseCommand(RobotPose pose)
{
    auto msg = rm_decision_interfaces::msg::SentryPose();
    msg.direction = "COMMAND";
    msg.pose_type = poseToCommandString(pose);  // "ATTACK"/"DEFENSE"/"MOVEMENT"
    msg.is_valid = true;
    msg.timestamp = node_->now().nanoseconds();
    
    command_pub_->publish(msg);
    
    RCLCPP_INFO(node_->get_logger(), "Published pose command: %s", msg.pose_type.c_str());
}
```

### 6.2 结果反馈处理

导航系统订阅同一 Topic 并处理反馈：

```cpp
result_sub_ = node_->create_subscription<rm_decision_interfaces::msg::SentryPose>(
    "/sentry/pose", 10,
    [this](const rm_decision_interfaces::msg::SentryPose::SharedPtr msg) {
        // 只处理 RESULT 方向的消息
        if (msg->direction != "RESULT") {
            return;
        }
        
        last_result_success_.store(msg->success);
        last_result_message_.store(msg->message);
        result_received_.store(true);
        
        if (msg->success) {
            RCLCPP_INFO(node_->get_logger(), "Pose command succeeded: %s", msg->message.c_str());
        } else {
            RCLCPP_ERROR(node_->get_logger(), "Pose command failed (code=%d): %s", 
                        msg->error_code, msg->message.c_str());
        }
    });
```

## 8. 常见问题

### Q1: 电控系统收不到指令？
- 检查 Topic 名称是否一致
- 检查消息类型是否匹配
- 使用 `ros2 topic list` 确认 Topic 已创建

### Q2: 导航系统收不到反馈？
- 检查电控系统是否正确发布结果
- 检查 result_code 的含义
- 确认 QoS 策略一致

### Q3: 姿态切换失败？
- 检查机械系统是否正常
- 检查电量是否充足
- 查看电控系统日志
