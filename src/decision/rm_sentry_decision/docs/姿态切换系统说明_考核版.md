# 机器人姿态切换系统说明（上传版）

## 一、系统展示目标
本说明用于展示哨兵机器人“移动、进攻、防御”三种姿态的切换逻辑，说明在不同战场状态下机器人如何自主做出姿态决策，并通过实机演示验证该系统的稳定性与可复现性。

## 二、姿态定义
机器人包含三种核心姿态：
1. 移动姿态：用于机动转点、巡航与战术转移。
2. 进攻姿态：用于到点后定点作战展示。
3. 防御姿态：用于低血量回撤、保守机动与返航补给。

## 三、场景设置
演示场地包含三个关键区域：
1. 补给点（Supply）：机器人返航补给与恢复循环的基准点。
2. 第一作战点（P1）：首个到达点，用于进攻姿态驻留展示。
3. 第二作战点（P2）：第二个到达点，用于再次进攻展示与低血返航触发。

演示路径由“补给点 -> P1 -> P2 ->（低血）补给点 ->（恢复）继续循环”构成。

## 四、触发条件
系统触发分为三类：
1. 启动触发：比赛状态进入运行阶段后，整套流程开始执行。
2. 低血触发：当机器人血量低于设定阈值时，立即切换为防御姿态并返航补给点。
3. 恢复触发：机器人回补给点后，血量恢复到设定值以上，再次进入巡航与作战循环。

## 五、决策链路（业务逻辑）
### 1) 启动阶段
1. 机器人等待比赛进入可执行阶段。
2. 启动后先以移动姿态前往 P1。
3. 到达 P1 后切换进攻姿态并保持一段时间，完成定点进攻展示。
4. 随后切换防御姿态，以较低速度前往 P2。
5. 到达 P2 后再次切换进攻姿态并保持一段时间。

### 2) 循环阶段
系统持续进行“状态判断 -> 路径选择”：
1. 若血量正常：继续在 P1 与 P2 之间执行“移动/防御机动 + 进攻驻留”的展示循环。
2. 若血量过低：立即中断当前循环，切换防御姿态返航补给点。

### 3) 回补与重入
1. 返航到补给点后，系统进入恢复等待。
2. 血量达到恢复条件后，自动重新进入前述循环流程。

## 六、姿态与速度策略
本演示采用“进攻驻留 + 分段限速”的策略：
1. 去 P1 的机动速度高于防御机动速度，体现主动机动能力。
2. P1 到 P2 以及返航补给段采用更低速度，体现防御回撤特征。
3. 进攻姿态阶段在目标点原地保持，突出姿态切换效果。

## 七、视频拍摄说明（按考核要求）
### 1) 画面建议
1. 全景机位：展示完整路径与点位关系（补给点、P1、P2）。
2. 侧向近景：展示姿态切换时的状态变化与到点驻留。
3. 屏幕机位：展示触发过程与状态变化结果，辅助说明决策链路。

### 2) 讲解建议
拍摄讲解按“场景 -> 触发条件 -> 决策链路 -> 结果验证”顺序进行：
1. 先说明三种姿态在战术上的作用。
2. 再说明启动、低血、恢复三个触发条件。
3. 最后按时间线解释机器人每一步为什么切换姿态、为什么返航、为什么恢复循环。

### 3) 合规要求
实机演示过程中不使用遥控器等人为操控信号设备，所有展示均基于系统自主触发与决策执行。

## 八、可靠性验证结论（演示判据）
演示通过的判据如下：
1. 姿态切换顺序与场景逻辑一致，且能多轮重复。
2. 低血触发后能够稳定返航补给点。
3. 回补后能够按条件恢复作战循环。
4. 全过程无人工遥控介入，满足自主决策展示要求。
