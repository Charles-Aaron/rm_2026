## 智能补给决策矩阵

```
SelectSupplyPoint 决策逻辑:

HP ≤ 100 → 基地补给点
HP 100-130 → 根据敌我血量差选择
HP 130-180 → 根据敌我血量差选择
HP > 180 → 基地补给点

敌我血量差判断:
- 差值 ≥ 90 → 基地补给
- 差值 60-90 → 前哨站补给  
- 差值 < 60 → 前哨站补给
- 敌人阵亡 → 视为差值足够小
```
